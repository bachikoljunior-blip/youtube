**どこを見るか（PC の場合）**

1. `studio.youtube.com` を開く
2. 左のメニューの**「アナリティクス」**
3. 上のタブに**「リーチ」**（無ければ**「コンテンツ」**）
4. その中の **「インプレッション」** と **「インプレッションのクリック率」**

**スマホの YouTube Studio アプリの場合**: 動画を1本開く →「アナリティクス」→
横にスクロールして**「リーチ」**。

**タブの名前は変わります。** 見つからないときは、**「インプレッション」という
言葉を画面から探してください。** それが目的の数字です。

**見てほしいのは長尺です**（ショートはフィード配信なので、この数字が出ないことがあります）:

    G3VqIFpBwKo  年収660万円の給与所得控除 …      公開 8/11 19:00・**再生3**
    m_q1G_GNgY8  残業代 計算 手当 含まれないもの   公開 8/10 19:00・**再生4**

**知りたいのは1つだけ: インプレッションが「ほぼ0」か「数百以上」か。**

- **ほぼ0** なら、**サムネと題を直しても意味がありません**（そもそも表示されていない）。
  長尺は検索とおすすめに載っていない、が確定します
- **数百以上あって再生が3** なら、**表示はされていて押されていない。**
  サムネと題の作り直しに、初めて意味が出ます
