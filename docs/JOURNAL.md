# 投稿の日誌

**追記だけ。過去の行を書き換えないこと。**

毎日の投稿は、常駐セッションに定期実行が撃ち込まれる形で回っています。そのセッションは
永遠には続きません。文脈が伸びれば要約されて薄れますし、いつか別のセッションに引き継ぐ
ことになります。

そのとき失われるのはコードではなく**判断の理由**です。何を試して効かなかったのか、
なぜその切り口をやめたのか、いつ何を変えたのか。YouTube 側は「何をいつ出したか」と
「どうなったか」しか持ちません。**「なぜそうしたか」を持つ場所がここです。**

## 書き方

1回の投稿につき数行。長さより、書いてあること。**見出しに自分のセッションIDを
書いてください**（システムプロンプトの Claude-Session の URL にあります）。

```
## 2026-08-05  (session_01AbCdEf...)
- …
```

書く価値があるのは、**数字を見ても分からないこと**だけです。何を出したかは
チャンネルに、成績はアナリティクスにあります。ここに要るのは、その数字を見て
何を考え、何を変え、何を変えなかったか。変えなかった理由のほうが、しばしば有用です。

**読むのは末尾10件ほどで足ります。** このファイルは伸び続けるので、全部読む必要は
ありません。古い記入が要るのは、いま触っている箇所の経緯を辿るときだけです。

## 毎回、必ず読み直すこと

**前回の記憶で動かないでください。** 同じセッションに撃ち込まれ続けるので、
「昨日これをやった」という感覚は残っています。その感覚は、日が経つほど薄れていく
一方で、薄れたことには気づけません。

だからいつも、このファイルとチャンネルの実績を読み直してから判断してください。
**1回の実行が独立していれば、このセッションは伸び続けても構いません。**

## 引き継ぐとき

乗り換えは、伸びたからではなく **セッションが落ちたとき** か、**別の環境に移すとき**
にだけ必要になります。手順は [`KICKOFF.md`](KICKOFF.md) にあります。

## 2026-08-04  (session_01PXy8TiBxL1SM7AUc6XAMML・立ち上げ)

- 構成を GitHub Actions から常駐セッションに切り替えた。Actions 版だと台本生成のために
  `CLAUDE_CODE_OAUTH_TOKEN` をリポジトリの Secrets に置く必要があり、鍵が1つ増える。
  セッション内で思考すればその鍵は要らない。あわせて Actions の無料枠（private リポジトリで
  月2,000分）の制約も外れ、投稿頻度が実行時間に縛られなくなった。
- 認証情報は環境「Youtube」(env_01QMJaP2yRCzw4tY5VpJeM1m) の環境変数に置く。
  リポジトリにも会話にも残らない。**環境変数は設定後に始まるセッションにしか入らない**ので、
  値を変えたらセッションを作り直すこと。
- 映像はフリー素材をやめ、図解を HTML で組んで Chromium で撮る方式にした
  （stat / table / steps / compare の4種）。素材が全部自前になるので、
  YouTube の「量産された無個性コンテンツ」判定に対する材料になる。
  ただしこれだけでは足りない。自分の声を入れるのが最も効く（STRATEGY.md の §5）。
- 音声は open-jtalk を既定にした。鍵も課金設定も要らないが、声は明確に機械的。
  `GOOGLE_TTS_API_KEY` を環境変数に足せば Neural2 に切り替わる。
  声は視聴維持率を通して収益に効くので、続ける気があるなら足す価値がある。
- 投稿済みの記録はファイルに持たない。説明欄の末尾に `[t:テーマID]` を埋め、
  毎回チャンネルから読み直す。動画を消せば記録も消えるので、記録が実体とずれない。
- 投稿前に検査を通す。尺・解像度・音声トラック・冒頭フレームのどれかが外れたら
  投稿しない。壊れた動画が本番に出るより、その日1本落ちるほうがいい。
