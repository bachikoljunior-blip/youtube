### 走っている子がいるなら、立てないこと（2026-08-15 に足した）

**毎時になり、子の1回が重くなったので、重なるようになりました。**
`parent_session_id` が自分の子のうち **`PENDING` / `RUNNING` / `IDLE`** が
1つでもあるなら、**この回は立てない。** 出力も無し（未処理の指示が無ければ）。

重なると何が起きるか: **同じ枠を2人で食い、同じ生成を2回やり、
予約時刻がぶつかります。** 毎時の cron は「1時間ごとに必ず立てる」ではなく、
**「空いていたら次を立てる」** の意味で読むこと。

**詰まった子を畳んだ回は、そのまま1つ立ててよい**（同じターンで）。

**オーナーが子と会話している回もあります。** その子は畳むまで生きているので、
鎖はそのあいだ止まります。**それでよい**（会話のほうが速い）。
