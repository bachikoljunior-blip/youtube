# 収益戦略と、正直な見通し

## 1. 収益の式

```
月間広告収益 = 月間再生数 ÷ 1000 × RPM
```

RPM（1000再生あたりの手取り）は**ジャンルで10倍以上変わります**。
ここの選択が、投稿本数や編集の質より遥かに効きます。

| ジャンル（日本語・長尺） | RPM の目安 |
|---|---|
| 金融・投資・保険・税金 | ¥800〜2,000 |
| 不動産 | ¥800〜1,500 |
| ビジネス・キャリア・転職 | ¥600〜1,200 |
| IT・ガジェット | ¥400〜800 |
| 教育・雑学 | ¥300〜600 |
| エンタメ・Vlog | ¥150〜400 |
| **ショート動画** | **¥50〜150** |

このリポジトリの既定ニッチを「お金・税金・キャリアの実務解説」にしているのは、
**RPM が最上位帯で、かつ AI で調べて書ける情報量が多い**からです。

**ショートは収益目的では選びません。** 同じ再生数でも長尺の1/10以下にしかなりません。

> **2026-08-04 追記：この一文は、収益化前の局面では誤りです。**
> 収益化されるまで収入は**どちらもゼロ**なので、その間 RPM の比較には意味がありません。
> 門の条件は「登録者1,000人 **かつ** 総再生4,000時間」で、登録者はもう一方の必須条件です。
> 認知ゼロのチャンネルが登録者を集める手段として、ショートは検討に値します。
> ただしショートは量産判定を受けやすい形式でもあるので、採るなら §5 の条件を満たす
> 作り方が要ります。**まだ採用していません。次に検討する候補として残します。**

## 2. 「月20万円」に必要な数字

RPM ¥1,000（金融・キャリア系の長尺）で計算すると:

| 目標 | 必要な月間再生数 | 1日あたり |
|---|---|---|
| 月 ¥50,000 | 50,000 回 | 約 1,700 回 |
| 月 ¥100,000 | 100,000 回 | 約 3,300 回 |
| **月 ¥200,000** | **200,000 回** | **約 6,700 回** |

毎日1本・3か月で90本の在庫を作った場合、
**1本あたり月2,200回**まわれば到達します。1本で万バズを狙う必要はありません。

## 2-b. 律速は「登録者」であって「総再生時間」ではない（2026-08-04 追記）

門は「登録者1,000人 **かつ** 総再生4,000時間」です。ここまでこのファイルは
4,000時間の側だけを計算していました。**もう一方を同じ真剣さで計算していなかった。**

- 4,000時間 ＝ 10分・維持率40%（1回4分）なら **約6万再生**
- 登録者1,000人 ＝ 登録率0.3%なら **約33万再生**

税や労務の検索流入は「用が済んだら去る」種類の視聴で、実用系の登録率は
おおむね 0.1〜0.5% と言われます（ここは推測です。実測したら差し替えること）。
仮に0.3%なら、**登録者側は総再生時間側の5倍以上の再生を要求します。**

**つまり律速は登録者です。** そして長尺の検索流入は、登録者を増やす力が最も弱い形式です。
いまの構成は、門の「効いていない側」だけを最適化していることになります。

### 未検証の前提（もっと重要）

**登録者0のチャンネルが、そもそも検索面に表示されるのか。** これを確かめていません。
日本語のお金ジャンルは占有度が高く、新規チャンネルは数か月インプレッションが
出ないことがあります。「良い計算を出せば検索が拾う」は推測であって数字ではありません。

**1本目の公開から24〜48時間のインプレッション・CTR・流入経路が、これを決めます。**
表示すらされないなら、本数を増やしても効きません。そこを見るまで、本数を増やす方向に
資源を寄せすぎないこと。

### 出てくる形

- **長尺** … 総再生時間を積む役。いまの計算主体の作りはここでは正しい。
- **ショート** … 認知ゼロのチャンネルに露出が出る唯一の面。**登録者を集める役。**
  §1 で「RPMが低いから選ばない」と書いたのは、収益化前の局面では誤りです
  （収益化前はどちらも収入ゼロなので、RPM の比較に意味がない）。
  訂正はしたが**まだ手を打っていない。** ここが最大の空白です。

ショートを作るなら、量産判定を避ける条件は長尺と同じです。
**1本＝1つの計算結果**にすれば、切り口も図も毎回変わり、条件を満たせます。

## 3. その前に、収益化の門がある

広告収益を1円でも受け取るには、YouTube パートナープログラムの承認が要ります。

- チャンネル登録者 **1,000人**
- 直近12か月の総再生時間 **4,000時間**

4,000時間 = 240,000分です。10分動画・視聴維持率40%（=1回4分）なら、
**約60,000回の再生**で到達します。

**現実的な期間**: 毎日投稿を続けて、テーマが刺されば **4〜8か月**。
そこから月20万円までは、さらに **半年〜1年**。刺さらなければ到達しません。

「最短で月20万」という目標に対して、最短ルートは
**毎日投稿を止めないこと**と**週次でテーマを実績に寄せること**の2つだけです。
このリポジトリはその2つを自動化しています。

## 4. このパイプラインが収益のためにやっていること

| 実装 | 収益への効き方 |
|---|---|
| 8分超を強制（`min_minutes: 8.5`） | ミッドロール広告を複数入れられる。RPM が最大の要因 |
| 冒頭で結論を言い切る台本ルール | 冒頭30秒の離脱を抑える。視聴維持率は広告表示回数に直結 |
| 全編に字幕を焼き込み | 無音視聴・ながら視聴での離脱を抑える |
| セグメントごとに図解が切り替わる | 画変わりがないと維持率が落ちる |
| 投稿前に尺・解像度・音声・冒頭を検査 | 壊れた動画が本番に出るのを止める |
| チャプター自動生成 | 検索流入と、途中から見た人の滞在時間が伸びる |
| 実績を見てテーマを更新 | 伸びたテーマの隣接に寄せる。**これが複利で効く唯一の仕組み** |
| 煽らないタイトル・サムネ | 広告主フレンドリー判定。扇情的だと RPM が下がるか広告制限になる |
| 19時 JST 予約公開 | 日本の視聴ピークに初速を作る |

## 5. これはリスクではなく、到達可能性の条件（2026-08-04 に書き換え）

**以下は当初「リスク」として書いていました。それは読み違いです。**
ポリシーに該当すれば収益化されず、収益化されなければ RPM がいくつでも収入はゼロです。
つまりこれは確率的なリスクではなく、**満たさなければ目標に到達できない条件**です。

公式ヘルプが収益化の対象外として挙げているもののうち、この作りに直接あたるのは3つ。

> クリエイターならではの、率直な洞察や視点が追加されておらず、汎用的または独創性のない
> テンプレートを使用して作成され、大量生産されたような印象を与える AI 生成コンテンツ

> テンプレートを使用して作成されたと思われるコンテンツや、同じチャンネルの動画を
> 続けて数本視聴した後、繰り返しのように感じられる可能性のあるコンテンツ

> ウェブサイトやニュース フィードのテキストなど、自分で作成していない他の資料の内容を
> 読み上げただけのコンテンツ

**制度のまとめ直しは、どれだけ丁寧でも3つ目に落ちます。** 図解を自前にしても、
毎回同じ版面・同じ声・同じ構成なら2つ目に落ちます。だから対策は装飾ではなく、
**中身の性格を変えること**でした。

### 採った対策

**制度を解説するのではなく、自分で計算した結果を発表する。**
`src/calc/` に毎回計算を実装し、どこにも公開されていない数字を出す。**前提と計算式を
画面と説明欄に全部出す。** 前提の置き方が「独自の視点」であり、視聴者が自分で追試できる
ことがテンプレート量産との違いになります。

> **このリポジトリの存在は、動画・説明欄・コメント・タイトルのどこにも出しません。**
> リンクも名前も匂わせも書かないこと。検証可能性は、前提と計算式を画面に出すことで
> 担保します。**目標側の理由**: 自動生成の出どころを自分から明かすのは、
> 「大量生産されたような印象」の判定材料をこちらから提供する行為だからです。

あわせて、`kind=chart` の棒の長さは計算結果そのもの、配色はテーマIDから決まるので、
**回ごとに図の形と色が変わります。**

### まだ足りていないもの

1. **自分の声。** 最も効きますが、人の作業に依存します。目標本文が
   「私が必ず読むとは限りません」と言っている以上、**これを前提にした計画は立てません。**
   やってもらえたら上振れする、という位置づけに留めます。
2. **実際の画面の収録。** 申告書の実物、公式サイトの該当ページ、計算ツールの操作。
   これは人手なしでもできる余地があります。次に手を入れるならここです。

## 5-b. 旧記述（当初の見立て。残しておく）

YouTube は 2025年7月のポリシー更新で、
**大量生成・反復的で独自性のないコンテンツは収益化対象外**と明示しました。

AI の利用そのものは禁止されていません。禁止されているのは
**同じテンプレートの繰り返しで、独自の付加価値がないもの**です。

合成音声 + 字幕 という構成は、**何もしなければまさにそのパターンに見えます。**
YPP 申請時に落とされる最大の要因はここです。

ストック素材をやめて図解を自前で描いているのは、この一点のためです。
ただし**それだけでは足りません。** 下の1と3を足せるかどうかで結果が変わります。

### 対策（重要度順）

1. **自分の声を入れる。** 最低でも冒頭の結論部分だけでも自分で録る。
   最も効果が大きく、最も面倒。それでもやる価値があります。
2. ~~オリジナルの図表を入れる~~ → **実装済み**。`src/visuals.py` が条件分岐表・
   金額・手順・二択の図解を HTML で組み、Chromium で撮っています。
   ストック素材は一切使っていません。
3. **実際の画面を映す。** 申告書の実物、公式サイトの該当ページ、計算ツールの操作。
4. **台本を毎回読む。** 事実誤認をそのまま出すと、訂正コメントで信頼を失い、
   維持率が落ち、収益も落ちます。制度系は特に。
5. **テーマを分散させる。** 同じ話の焼き直しを連投しない（週次最適化がある程度やります）。

`visibility` を最初 `private` にしてあるのは、**あなたが必ず1本目を見るため**です。

## 6. 途中で見る数字

YouTube Studio のアナリティクスで、この3つだけ追ってください。

| 指標 | 見方 |
|---|---|
| クリック率(CTR) | 4%未満ならサムネとタイトルが弱い。`thumbnail_line1` の作り方を変える |
| 平均視聴率 | 30%未満なら台本の冒頭が弱い。`src/script_writer.py` の `ROLE` の冒頭ルールを強める |
| RPM | ¥500未満ならニッチが弱い。`config/channel.yaml` の `niche` を上の表の上位に寄せる |

CTR と平均視聴率は掛け算で効きます。どちらかが半分なら再生数は半分です。

| 図解の素材 | **$0**（自前で描いて撮る。ストック素材サービスを使わない） |
| 実行環境 | **$0**（Claude Code の常駐セッション。GitHub Actions を使わないので実行時間の枠も無い） |

**追加の実費は $0。** すでに払っている Claude のサブスク費用だけで回ります。

ただしサブスクの利用枠は普段の Claude Code 作業と共有です。台本1本の生成は
通常の作業に比べれば小さいものの、上限に当たりやすいなら次のどれかで下げられます。

- `config/channel.yaml` の `generation.model` を `sonnet` に落とす
- 定期実行トリガーの cron を隔日にする（KICKOFF.md 参照）
- 実行時刻を、自分が Claude Code を使わない時間帯にずらす
