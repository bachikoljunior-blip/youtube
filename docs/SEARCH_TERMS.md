# 検索語の実測候補（2026-08-09 取得）

**推測で長尺を作らないための正本。** 出どころは ChatGPT（M6 の経路、
`chatgpt-ask.yml`）で、日本語サジェスト・関連検索に出る表現を整理させたもの。
**検索量の保証ではない**（先方も明記）。ここから作った動画の実績で確かめる。

## なぜ要るか

長尺を7本出して**全部0〜1再生**。28日ぶんの検索語を実測したら、
お金関連の検索が**1件も無かった**（全部チャンネル前身の名残）。
**「検索に載る長尺」を作れていない**のが正体で、
題材を推測で選んでいたことが原因と考えられる。

## 差別化の型（これが要点）

> **「制度名＋入力条件＋計算結果／比較」**
> 「徹底解説」「知らないと損」では大手と同じになる。

**これは `src/calc/` がやっていることそのもの。** 型は既に持っている。
足りなかったのは**検索語に合わせて題を選ぶこと**だった。

### 8/9 に追加で測った語（`tedori` 用）

**自分で推測して選びかけたので、他と同じ経路で確かめ直した。** 結果は3件中2件が外れ。

| 語句 | 評価 | 備考 |
|---|---|---|
| 年収 上がっても 手取り 増えない | **やや厚い** | 大手が周辺テーマを多数扱っている。避ける |
| 昇給 手取り いくら増える | **中程度** | 税理士法人の「年収100万円上がったら手取りはいくら増える？」がほぼ同じ企画 |
| 年収660万円 給与所得控除 | **薄い** | ここに寄せる |

他に挙がった候補: 昇給50万円 手取り／年収別 限界手取り率／
年収が上がっても手取りが増えない理由。
**主軸は「年収50万円上がったら手取りはいくら増える」、補助語に
「年収660万円の壁」「限界手取り率」**、という組み合わせが勧められた。

**言い方の注意（先方が指摘）**: 660万円で控除額が不連続に減るのではなく、
**追加年収に対する増え方**が20%から10%に落ちる。
「控除が減る」「1円超えると損」は誤りなので使わない
（`src/calc/tedori.py` の `SALARY_DEDUCTION_KNEE` に検算つきで書いてある）。

**逆に大手が非常に強い**（避ける）:
「年金 繰上げ／繰下げ」「ふるさと納税 上限」「失業保険 いくら」の**単体**。

## 作り方の指針（先方の回答から）

- **1動画1クエリ。** タイトル前半に検索語をほぼそのまま置く。
  冒頭15秒でも同じ語と結論の数字を発話する
- **尺は4〜7分。** 9〜11分に引き延ばす必要はない
- **まず同一テーマで15〜25本。** 一度に広げず、
  例えば「医療費控除の実算」を年収・医療費別に8〜10本、次に関連テーマ
- **登録者数の最低条件は無い。** 検索順位の主因は関連性・エンゲージメント・品質
- **7本・0〜1再生だけでは判定できない。** ただし前身の履歴は初期視聴者との
  不一致を起こしうるので、金銭計算以外を投稿せず、名前・概要・再生リストを統一する
